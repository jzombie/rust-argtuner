# Plan: Move test mock emit binaries into an unpublished `argtuner-mock-bin` crate (artifact-dep design)

## Motivation

The `src/bin/emit_*.rs` binaries are test-only mock subprocesses that live in the publishable
`argtuner` package. Move them into a dedicated **unpublished** workspace crate, expose them via
Cargo's native **artifact dependency** mechanism (RFC 3028), and delete the orphaned ones.

## Where the mock bins are called from

`test_support::bin_command("<bin>")` produces the shell command used as a `CommandTemplate`;
`CommandRunner::run()` executes it per trial. Callers:

| Binary | Callers |
|---|---|
| `emit_result` | `src/sampler/pso.rs:509`; `src/checkpoint.rs:312`; `src/command/objective.rs:495`; `tests/trial_flow.rs:7`; `tests/tuner_resume.rs:10`; `tests/dry_run.rs:9`; `tests/artifact_preservation.rs:11`; `tests/duplicate_configs.rs:5` |
| `emit_env_result` | `src/checkpoint.rs:544`; `src/command/objective.rs:687, 987, 1073` |
| `emit_invalid_result` | `src/command/objective.rs:499` |
| `emit_x_used` | `src/command/objective.rs:503` |
| `emit_binding_version` | `tests/binding_version_mismatch.rs` |
| `emit_result_marker` | **no callers → DELETE** |
| `emit_invalid_then_ok` | **no callers → DELETE** |

## Changes

### 1. New workspace member `crates/mock-bin/`

- `crates/mock-bin/Cargo.toml`:
  - package `argtuner-mock-bin`, `version.workspace = true`, `edition.workspace = true`,
    `license.workspace = true`, **`publish = false`** (explicit — never inherits the workspace
    publish flag).
  - deps: `argtuner-common.workspace = true`, `argtuner-talkback.workspace = true`.
- Move the **five** used bins → `crates/mock-bin/src/bin/emit_*.rs`:
  `emit_result`, `emit_env_result`, `emit_invalid_result`, `emit_x_used`, `emit_binding_version`.
- Add a crate-level `//!` doc comment: test-only mock subprocesses, never published.

### 2. Delete dead code

- Remove `src/bin/emit_result_marker.rs` and `src/bin/emit_invalid_then_ok.rs` (zero callers).

### 3. `argtuner` — native artifact dependency

In root `Cargo.toml`:

```toml
[workspace]
members = ["bindings/rust", "bindings/talkback-derive", "crates/common", "crates/mock-bin"]

[dev-dependencies]
argtuner-mock-bin = { path = "crates/mock-bin", artifact = "bin" }
```

- `artifact = "bin"` builds the mock crate's binaries and, when compiling argtuner's test
  targets, populates `CARGO_BIN_EXE_emit_result`, `CARGO_BIN_EXE_emit_env_result`, etc. with
  **fresh** absolute paths — no manual builds, no stale binaries, and Cargo serializes the
  compilation itself (no inter-process lock races).
- Declared as a direct path in `[dev-dependencies]` (a `workspace = true` + `artifact`
  combination is not reliably supported; a `[workspace.dependencies]` entry may be added later
  if desired).

### 4. `src/test_support.rs` — strip to env-var lookup only

Replace `command_path` + the `cargo run` fallback with a pure env-var read:

```rust
/// Absolute path to a compiled mock binary provided by the
/// `argtuner-mock-bin` artifact dev-dependency.
pub fn bin_path(bin: &str) -> PathBuf {
    let env_key = format!("CARGO_BIN_EXE_{bin}");
    std::env::var(&env_key)
        .map(PathBuf::from)
        .unwrap_or_else(|_| panic!("{env_key} is unset; is argtuner-mock-bin an `artifact = \"bin\"` dev-dependency?"))
}

pub fn bin_command(bin: &str) -> String {
    shell_words::quote(&bin_path(bin).to_string_lossy()).to_string()
}
```

- No filesystem polling, no `CARGO_BIN_EXE` + `target/debug` fallback chain, no `cargo` spawn.
- Update the module `//!` docs.

### 5. `tests/binding_version_mismatch.rs`

- Replace the manual `cargo build -p argtuner --bin emit_binding_version` + `target_dir`
  lookup with `argtuner::test_support::bin_path("emit_binding_version")` (reads
  `CARGO_BIN_EXE_emit_binding_version`, set by the artifact dep for integration tests).
  Delete the `Command::new("cargo")` block and the `target_dir`/`argtuner_bin` discovery
  (keep `current_exe`-based argtuner path discovery or reuse the same bin_path-style helper —
  argtuner's own `CARGO_BIN_EXE_argtuner` is also set by cargo for integration tests).

### 6. Remove `argtuner`'s `src/bin/`

- All bins moved or deleted → remove the now-empty `src/bin/` directory.
- `default-run = "argtuner"` still resolves to `src/main.rs`.

## Key risk / verification priority

**Does Cargo populate `CARGO_BIN_EXE_<bin>` for artifact deps in LIB UNIT tests**
(the PSO test at `src/sampler/pso.rs`) as well as integration tests? Verify first:

1. `cargo test -p argtuner --lib sampler::pso::tests::pso_end_to_end_checkpoint_persisted_and_restored -- --exact`
2. If it fails because the env var is unset in lib unit tests (an artifact-dep limitation),
   **contingency**: relocate the PSO test (and any other lib test using `bin_command`) to an
   integration test under `tests/`, where artifact-dep `CARGO_BIN_EXE_*` is guaranteed.

- `cargo build --workspace --all-targets` — mock crate builds; argtuner builds; no `emit_*`
  bins under argtuner.

  contention, no stale-binary path).
- `cargo test -p argtuner --lib` — confirms the lib-unit-test env-var question (or triggers
  the contingency).
- `cargo package -p argtuner --no-verify --allow-dirty` (or `--list`) — `emit_*` bins absent
  from the published package.
- `cargo clippy --workspace --all-targets --all-features -- -D warnings` and
  `cargo fmt --all -- --check` — clean.
