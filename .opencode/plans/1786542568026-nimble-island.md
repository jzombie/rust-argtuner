# Plan: Fold the SDK into `argtuner`, extract `argtuner-derive`, unify docs

## Target
```
rust-argtuner/
├── Cargo.toml          # single argtuner package (engine + CLI + SDK)
├── README.md           # single unified documentation
├── src/
│   ├── lib.rs          # SDK exports: init, Params, Talkback, is_tuning_active, emit_metrics!, talkback_args
│   ├── main.rs         # CLI binary (engine: tui, sqlite, pty)
│   └── sdk.rs          # folded SDK code (was bindings/rust/src/lib.rs)
└── crates/
    ├── argtuner-derive/ # proc macro (was bindings/talkback-derive)
    ├── common/          # argtuner-common (unchanged)
    └── mock-bin/        # test subprocesses (unchanged)
```
`bindings/` is removed. No `argtuner-talkback` crate, no `argtuner-core`/`argtuner-cli`.

## Changes

### Phase 1 — extract the derive crate
1. `git mv bindings/talkback-derive crates/argtuner-derive`; package → `argtuner-derive`.
2. `crates/argtuner-derive/src/lib.rs`: generated paths `::argtuner_talkback::` →
   `::argtuner::`; doc example stays `ignore` (no `argtuner` dev-dep — publish
   deadlock). No deps beyond proc-macro2/quote/syn.

### Phase 2 — fold the SDK into argtuner
1. `bindings/rust/src/lib.rs` → `src/sdk.rs`; adjust:
   - `pub use argtuner_derive::talkback_args;` (argtuner gains `argtuner-derive` dep).
   - Drop the `#[cfg(feature = "clap")]` gates (clap becomes a hard dep of argtuner,
     used by both the SDK and the CLI — no feature guessing).
2. `src/lib.rs`: remove the `argtuner_talkback`/`argtuner_talkback_derive` re-exports;
   add `mod sdk; pub use sdk::{BINDING_VERSION, init, is_tuning_active, Params, Talkback};`
   and `pub use argtuner_derive::talkback_args;`. (`emit_metrics!` is `#[macro_export]`
   → available as `argtuner::emit_metrics!`.)
3. `src/command/objective.rs`: `argtuner_talkback::BINDING_VERSION` → `crate::BINDING_VERSION`.
4. Root `Cargo.toml`:
   - workspace members → `["crates/argtuner-derive", "crates/common", "crates/mock-bin"]`;
     remove `argtuner-talkback`/`bindings` refs; rename `argtuner-talkback-derive` →
     `argtuner-derive` (path `crates/argtuner-derive`).
   - package `[dependencies]`: remove `argtuner-talkback` + `argtuner-talkback-derive`;
     add `argtuner-derive.workspace = true`; make `clap = { workspace = true, features = ["derive"] }`
     **non-optional**. Keep the `cli` feature for the heavy TUI deps; SDK is unconditional.

### Phase 3 — references & cleanup
1. `argtuner_talkback::` → `argtuner::` and `argtuner_talkback_derive::` →
   `argtuner_derive::` in `examples/*`, `tests/*`, `crates/mock-bin/src/bin/*`;
   `crates/mock-bin/Cargo.toml`: dep `argtuner-talkback` → `argtuner`.
2. Delete `bindings/` (rust folded, talkback-derive moved); delete stray
   `crates/argtuner/examples/` data files (untracked leftovers).
3. Unify docs: fold `bindings/rust/README.md`'s still-useful content into the main
   `README.md` (Quickstart, Declaring parameters, Protocol SDK blurb already cover
   it) and delete it; fix `bindings/`-relative links. One authoritative README.
