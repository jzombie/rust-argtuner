# Plan: Replace hand-rolled `space_entry_toml` with `serde` + `toml::to_string`

## Goal
Delete the string-concatenation TOML generation in `src/sdk.rs` and let serde +
`toml` produce spec-compliant output (escaping, floats, array-of-tables). The
SDK gains a `toml` dependency (already in the workspace, version 1.1).

## Changes (in `src/sdk.rs`)

### 1. Typed space model
```rust
#[derive(serde::Serialize)]
#[serde(tag = "type")]
enum SpaceParam<'a> {
    Float {
        name: &'a str,
        min: f64,
        max: f64,
        #[serde(skip_serializing_if = "is_false")]
        log_scale: bool,
        #[serde(skip_serializing_if = "Option::is_none")]
        step: Option<f64>,
    },
    Int {
        name: &'a str,
        min: i64,
        max: i64,
        #[serde(skip_serializing_if = "Option::is_none")]
        step: Option<i64>,
    },
    Choice {
        name: &'a str,
        values: &'a [&'a str],   // matches ParamHint.choices: &'static [&'static str]
    },
}

fn is_false(b: &bool) -> bool { !*b }
```

### 2. Replace `space_entry_toml` + string splicing with `toml_edit`
Delete `space_entry_toml`. Map tunable `ParamHint`s to `SpaceParam`, then build
the whole template via `toml_edit::DocumentMut` (safe mutation — `IndexMut`
auto-creates missing keys; preserves any comments in the starter):

```rust
pub fn render_template_toml<T: Params>() -> String {
    let template = render_template_command::<T>();
    let base = argtuner_common::render_starter_toml(&template);
    let mut doc: toml_edit::DocumentMut = base.parse().expect("starter template is valid TOML");
    let params: Vec<SpaceParam<'_>> = T::params()
        .iter()
        .filter(|p| p.is_tunable())
        .map(SpaceParam::from_hint)
        .collect();
    if !params.is_empty() {
        let item = toml_edit::ser::to_item(&params).expect("space params serialize to TOML");
        doc["space"]["params"] = item;
    }
    doc.to_string()
}
```
- No literal `[space]\nparams = []` replacement — the `[space]`/`[[space.params]]`
  structure comes from serde + toml_edit, so CRLF/Windows and any future
  `render_starter_toml` formatting changes are handled by the parser.
- `SpaceParam::from_hint` maps `ParamKind::Float/Int/Choice`
  (`Flag | Other` are excluded by the `is_tunable` filter).

### 3. Cargo.toml
Add `toml_edit = { version = "0.22", features = ["serde"] }` to
`[workspace.dependencies]` (the `serde` feature gates `toml_edit::ser`) and
`toml_edit = { workspace = true, features = ["serde"] }` to the `argtuner` crate
`[dependencies]`.

### 4. `SpaceParam::from_hint` — deterministic integer conversion
Int bounds/step round (not truncate) before the `i64` cast:
```rust
ParamKind::Int => SpaceParam::Int {
    name: &p.name,
    min: p.min.map_or(0, |f| f.round() as i64),
    max: p.max.map_or(0, |f| f.round() as i64),
    step: p.step.map(|f| f.round() as i64),
},
```
