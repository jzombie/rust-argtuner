## Changes by phase

### Phase 1 — crates
1. `git mv bindings/rust crates/argtuner`; rename package → `argtuner`;
   add `pub use argtuner_derive::talkback_args;`; keep deps
   (argtuner-common, serde, serde_json, optional clap).
2. `git mv bindings/talkback-derive crates/argtuner-derive`; rename package → `argtuner-derive`.
   **No `argtuner` dev-dependency** — a dev-dep would deadlock publishing (derive
   must publish before argtuner, but its dev-dep requires argtuner on the index).
   The doc example becomes `ignore` (noted with the publish rationale). Optional:
   a compile-fail check that the macro rejects generics/unnamed fields (needs no SDK).
3. `git mv` root package → `crates/argtuner-core` (src/, Cargo.toml, .github refs); rename package → `argtuner-core`;
   drop `[[bin]]`/`default-run`/`cli` feature/optional-dep gating (all deps non-optional);
   `src/main.rs` is NOT moved here (goes to argtuner-cli).
   `argtuner-core` gains a dependency on `argtuner` (the light SDK) to use
   `argtuner::BINDING_VERSION` for the version gate (heavy→light, no cycle;
   `BINDING_VERSION` stays `env!("CARGO_PKG_VERSION")` in the SDK — NOT moved to
   argtuner-common, so it always reflects the SDK's version).
4. New `crates/argtuner-cli`: `name = "argtuner-cli"`, `[[bin]] name = "argtuner"`,
   `src/main.rs` calls `argtuner_core::cli::run()`, deps: `argtuner-core` (+ `argtuner`
   for tests).
5. Root `Cargo.toml` → workspace-only (`[workspace]`, `[workspace.package]`,
   `[workspace.dependencies]`, keep `[package.metadata.cargo-udeps.ignore]` under
   argtuner-core); members = `["crates/*"]`; **`default-members = ["crates/argtuner-cli"]`**
   so root `cargo run`/`cargo build`/`cargo test` (no `-p`) work against the CLI
   (exactly one bin target → unambiguous).

### Phase 2 — import rewrites
- Engine (argtuner-core): `argtuner_talkback::BINDING_VERSION` in
  `src/command/objective.rs` → `argtuner::BINDING_VERSION` (argtuner-core deps on
  the SDK; the const stays `env!("CARGO_PKG_VERSION")` in `crates/argtuner`).
  Everything else in engine uses `crate::` (no change).
- SDK/examples/mocks: `argtuner_talkback::` → `argtuner::`;
  `argtuner_talkback_derive::talkback_args` → `argtuner_derive::talkback_args`
  (examples, mock-bin, tests).
- Integration tests → moved to `crates/argtuner-cli/tests/`, dev-deps on
  `argtuner-core` + `argtuner`; engine refs `argtuner::` → `argtuner_core::`.
  `CARGO_BIN_EXE_argtuner` keeps working (binary is in this package).
  `test_support::bin_path` → `argtuner_core::test_support`.
- **Relocated-test path fixes** (CARGO_MANIFEST_DIR is now `crates/argtuner-cli`):
  `include_str!("../README.md")` → `include_str!("../../README.md")`;
  showcase paths → `crates/argtuner/examples/config_showcase`; regenerate the
  README `<!-- config.inspect.output -->` block's `project:` line accordingly.
- `crates/argtuner/examples/config_showcase` moves with examples.

### Phase 3 — docs & CI
- README: `cargo run -p argtuner -- run …`/`argtuner …` CLI invocations →
  `cargo run -p argtuner-cli -- run …` / `cargo install argtuner-cli`;
  `-p argtuner --example …` stays. Update `cargo add argtuner` story +
  `argtuner-talkback`→`argtuner` in the Quickstart/Declaring-parameters/Protocol
  sections and bindings links (`./crates/argtuner/README.md`).
- `bindings/rust/README.md` → `crates/argtuner/README.md` content (already there).
- `.github/workflows/*`: commands use `--workspace` (already do); `default-run`
  removal is internal. Verify `cargo udeps`, `cargo test … --examples`,
  `cargo build --bins` still work.

### Phase 4 — delete
- Remove `bindings/` directory; remove `examples/`/`tests/` from the old root.
