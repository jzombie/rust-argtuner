# Plan: `#[talkback_args]` generates the clap interface — user defines a plain struct

## Vision
The user defines algorithm parameters in a **plain Rust struct** with `#[param(...)]`
hints. The derive generates the clap CLI (args, `--help`, defaults, parsing),
the command template, and a real `[space]` for `argtuner.toml` — all referencing
`argtuner_talkback::clap::…` (internal re-export), so the consumer's
`Cargo.toml` needs only `argtuner-talkback` (with `clap` feature) +
`argtuner-talkback-derive`. Metrics emit serde-free via `emit_metrics!` /
`talkback.metrics()`.

## New API (user-facing)

```rust
use argtuner_talkback_derive::talkback_args;

#[talkback_args]
struct ModelParams {
    /// Learning rate for optimization
    #[param(default = 0.001, min = 0.0001, max = 0.1, log = true)]
    lr: f64,
    /// Number of training steps
    #[param(default = 100, min = 10, max = 1000)]
    steps: usize,
    /// Optimizer implementation
    #[param(default = "adamw", choices = ["adam", "adamw", "sgd"])]
    optimizer: String,
    /// Checkpoint directory (reserved: trial_dir)
    #[param(value_name = "trial_dir")]
    checkpoint_dir: Option<String>,
}

fn main() {
    let (talkback, params) = argtuner_talkback::init::<ModelParams>();
    let loss = train(params.lr, params.steps, &params.optimizer);
    argtuner_talkback::emit_metrics! { "loss" => loss, "epoch" => params.steps };
    // or: talkback.metrics().record("loss", loss).record("epoch", params.steps).emit()?;
}
```
- `--help`, defaults, and validation come free (clap generated internally).
- `--print-template-toml` prints a full `argtuner.toml` with a populated `[space]`
  (Float/Int/Choice from `#[param]` hints); unannotated `Option`/scalar fields are
  fixed CLI flags.
- No `clap`/`serde` in the consumer's `Cargo.toml`.

## Changes

### 1. `bindings/rust/src/lib.rs`
- Add re-exports: `#[cfg(feature = "clap")] pub use clap;` and `pub use serde;`.
- Define the contract the derive implements:
  ```rust
  pub struct ParamSpec { name, long, value_name, default, help, kind, min, max,
                         log, step, choices: &'static [&'static str] }
  pub trait Params: Sized {
      fn app_name() -> &'static str;
      fn params() -> &'static [ParamSpec];
      fn command() -> clap::Command;            // derive-generated (typed value_parsers)
      fn from_matches(m: &clap::ArgMatches) -> Self;
  }
  ```
- Generic helpers over `T: Params`: `render_template_command::<T>()`,
  `render_template_toml::<T>()` (template + real `[space]` from `params()`),
  `maybe_print_template_and_exit::<T>()`, and `init::<T>()`. `init` **pre-inspects
  raw `std::env::args()`** for `--print-template`, `--print-template-toml`, and
  `--print-protocol-schema` and exits 0 with the generated output BEFORE ever
  building/running `T::command()` — the control flags are never handed to
  `clap::get_matches()`. Only then: version handshake (gated by
  `is_tuning_active()`) and `T::from_matches(&T::command().get_matches())`. Drop
  the `clap::Parser + CommandFactory` bounds; `init_with_args` becomes an alias.
- Serde-free emission (no user serde):
  - `#[macro_export] macro_rules! emit_metrics` — **fully-qualified** expansion,
    and the key matcher is `$key:expr` (not `:literal`) so keys can be variables,
    `&str` slices, or `format!(…)`:
    ```rust
    #[macro_export]
    macro_rules! emit_metrics {
        ($($key:expr => $value:expr),* $(,)?) => {{
            let mut map = ::std::collections::BTreeMap::<
                ::std::string::String, ::std::string::String
            >::new();
            $(
                map.insert(
                    ::std::string::ToString::to_string(&$key),
                    ::std::string::ToString::to_string(&$value),
                );
            )*
            $crate::emit_epoch_end(&map)
        }};
    }
    ```
  - `Talkback::metrics()` → `MetricsBuilder` with `record(k, impl ToString)` /
    `emit() -> io::Result<()>` (gated).
  - Keep the serde-based emitters for power users.
- Keep `is_tuning_active()` gating as-is (all emitters no-op standalone).
- **`ParamSpec::is_tunable(&self) -> bool`** (used by `render_template_toml`):
  a field is tunable ONLY if it has range hints (`min`/`max`) or `choices`.
  Excluded from `[[space.params]]`: reserved placeholders
  (`value_name` ∈ {"trial_dir", "trial_id"}), boolean flags, and unannotated
  scalar fields (fixed CLI args). `render_template_toml` filters via
  `params().iter().filter(|p| p.is_tunable())`.

### 2. `bindings/talkback-derive/src/lib.rs` — rewrite `#[talkback_args]`
- Parse the struct (syn): fields, types, doc comments (`help`), `#[param(...)]`.
- **AST type handling**: unwrap `Option<Inner>`, `std::option::Option<Inner>`,
  `core::option::Option<Inner>` to `Inner` for `value_parser!(Inner)`; mark such
  args **non-required**. `bool` → flag (`SetTrue`). Other types use
  `value_parser!` by concrete type (`f64`/ints/`String`/`FromStr`).
- **Requiredness**: non-`Option` fields WITHOUT a `default` hint get
  `.required(true)` on the `clap::Arg` (so clap prints a clean usage error rather
  than `from_matches` panicking); fields WITH a `default` get `.default_value(...)`.
- Generate `impl Params`:
  - `params()` — a `&'static [ParamSpec]` table (name, long = field with `_`→`-`
    or `#[param(long = …)]`, value_name, default as string, kind inferred from
    type + hints: `f64`+min/max→Float, ints→Int, `String`+choices→Choice, bool→Flag,
    `Option<T>`→optional; reserved `value_name` = "trial_dir"/"trial_id").
  - `command()` — clap builder via `argtuner_talkback::clap::{Command, Arg}`
    paths (typed value_parsers, required/default logic above, `.help`). For
    `#[param(choices = [...])]` fields: attach
    `.value_parser(argtuner_talkback::clap::builder::PossibleValuesParser::new([#(#choices),*]))`
    **only when the field type is `String`** (PossibleValuesParser yields
    `String`, matching `get_one::<String>`). For non-`String` fields, `choices`
    feed only the generated `[space]` (Choice entry) — the CLI keeps the typed
    `value_parser!(Inner)` + `get_one::<Inner>` path so no downcast can fail.
  - `from_matches(&ArgMatches)` — typed `get_one::<Inner>`/`get_flag` per field
    (no `.unwrap()` on missing non-required-without-default args, since clap
    enforces requiredness).
- `#[talkback_args]` no longer injects `--print-*` fields (flags handled by
  `init`); it stays on a **plain** struct (no `#[derive(Parser)]` needed).
