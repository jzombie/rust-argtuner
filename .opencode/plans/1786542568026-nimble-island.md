# Plan: Fix the "black-box / no internal hooks" claim in the README

## Problem
The "When it fits" bullet claims argtuner needs "no internal hooks", which is
misleading: the `argtuner-talkback` binding (bindings/rust + the
`#[talkback_args]` derive) is a first-class, optional integration path (typed
event emission, typed argv parsing, `--print-template` auto-generation, version
handshake). Accurate framing: argtuner never instruments model *internals*
(no gradients, no layer access); integration happens at the process boundary
via `::ARGTUNER::` JSON events on stdout, manually or via the binding.
