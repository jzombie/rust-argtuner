# Plan: Project discovery utility + CLI `find` + TUI Project Info window

## Goal
1. Add a library utility that recursively locates argtuner projects (dirs containing `argtuner.toml`) under a root dir.
2. Wire it up as a new `find` CLI subcommand in `src/main.rs`.
3. Add a new "Project Info" TUI window showing the project's paths and live trial count.

## 1. New module `src/discover.rs` (uses `ignore`)
- Replace the `walkdir` dependency with the `ignore` crate (ripgrep's engine):
  - Add `ignore = "0.4"` to `[workspace.dependencies]` in `Cargo.toml` and `ignore.workspace = true` to `[dependencies]`; **remove** the `walkdir` entries added earlier.
  - `ignore` is not yet in `Cargo.lock` (only `regex`/`walkdir` are), so this pulls in a few transitive deps (`globset`, `log`, `same-file`, `winapi-util`, …) — one-time build cost, no runtime cost.
- **No hardcoded blacklist.** The walker natively respects `.gitignore`, `.ignore`, git exclude, and global git config; skips hidden files/dirs by default; and does not follow symlinks (so `#[cfg(unix)]` symlink-loop test still passes). `target/`, `node_modules/`, `__pycache__/`, `venv/`, custom artifact dirs (`out/`, `.env`, …) are skipped automatically because they are git-ignored.
- `pub fn find_projects(root: &Path) -> Vec<PathBuf>`:
  ```rust
  use std::path::{Path, PathBuf};
  use ignore::WalkBuilder;
  use crate::constants::CONFIG_FILENAME;

  pub fn find_projects(root: &Path) -> Vec<PathBuf> {
      // Defensive: an empty root ("") yields undefined walker behavior and can
      // break the starts_with dedup below; normalize to the current dir.
      let root = if root.as_os_str().is_empty() {
          Path::new(".")
      } else {
          root
      };
      let mut results = Vec::new();
      // Defaults already give hidden(true), parents(true), git_ignore(true),
      // git_global(true), git_exclude(true), ignore(true). require_git is
      // forced OFF (it defaults to true) so git-ignore rules are honored even
      // outside a git repository — discovery must not depend on `git init`.
      let walker = WalkBuilder::new(root).require_git(false).build();
      for result in walker {
          let Ok(entry) = result else { continue }; // best-effort: skip unreadable
          // Direct &OsStr == &str comparison (OsStr: PartialEq<str>); no UTF-8
          // round-trip needed. No let-chains (stable across pre-1.88 toolchains).
          let is_config = entry.file_type().is_some_and(|ft| ft.is_file())
              && entry.file_name() == CONFIG_FILENAME;
          if is_config {
              if let Some(parent) = entry.path().parent() {
                  results.push(parent.to_path_buf());
              }
          }
      }
      results.sort();
      // Nested projects: keep a path only if it is not under an already-found one.
      // Sorting guarantees parents precede children; starts_with is component-aware
      // (no "/a" vs "/ab" false positives).
      let mut dedup = Vec::new();
      for path in results {
          if !dedup.iter().any(|parent: &PathBuf| path.starts_with(parent)) {
              dedup.push(path);
          }
      }
      dedup
  }
  ```
  - Note: `find .` is naturally correct here (no manual dir pruning / depth special-casing — we only collect `argtuner.toml` files, never filter the root).- Unit tests (in-module, using `tempfile`):
  - `finds_nested_projects` — nested + non-project dirs, exact ordering.
  - `respects_gitignore_and_hidden` — replaces `skips_noise_and_hidden_dirs`: write a `.gitignore` containing `target/` and a custom `out/`; assert projects under `target/` (git-ignored), `out/` (git-ignored, not hardcoded), and `.hidden/` (hidden) are all skipped, only `proj/` found. Works because `require_git(false)` applies `.gitignore` outside a git repo.
  - `respects_dot_ignore` — `.ignore` file listing a `custom/` dir; assert that project is skipped.
  - `empty_when_no_projects` — no projects found.
  - `nested_project_collapses_to_outermost` — a project nested inside another project's tree collapses to the outer one.
  - `symlink_loop_terminates` — `#[cfg(unix)]` (symlink creation needs elevated privileges on Windows; `ignore` default `follow_links(false)` guarantees termination).

## 3. CLI subcommand in `src/main.rs`
- Add to `Commands` enum (clap derive):
  ```rust
  /// Recursively locate argtuner projects
  Find {
      /// Directory to search (defaults to the current directory)
      #[arg(value_name = "DIR")]
      dir: Option<PathBuf>,
  },
  ```
- New match arm — **no `.expect()` and no `.clone()`**; handle `current_dir()` failure gracefully via a `Cow<Path>` (binds owned path only when needed):
  ```rust
  Commands::Find { dir } => {
      // `dir` is `&Option<PathBuf>` (outer `match &cli.command` borrows);
      // `.as_deref()` flattens to `Option<&Path>` so the Cow only owns the
      // current_dir fallback.
      let root: Cow<Path> = match dir.as_deref() {
          Some(d) => Cow::Borrowed(d),
          None => match std::env::current_dir() {
              Ok(d) => Cow::Owned(d),
              Err(e) => {
                  eprintln!("Error: failed to determine current directory: {e}");
                  std::process::exit(1);
              }
          },
      };
      let projects = argtuner::find_projects(&root);
      if projects.is_empty() {
          eprintln!("No argtuner projects found under {}", root.display());
      }
      for p in projects {
          println!("{}", p.display());
      }
  }
  ```
  - Add `use std::borrow::Cow;` and `use std::path::Path;` to `src/main.rs` imports (currently only `PathBuf` is imported).
- Add a unit test in the existing `cli_tests` module: `argtuner find` parses (dir optional); `argtuner find /tmp/x` parses with `dir == /tmp/x`.
