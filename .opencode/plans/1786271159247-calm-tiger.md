# Plan: Project discovery utility + CLI `find` + TUI Project Info window

## Goal
1. Add a library utility that recursively locates argtuner projects (dirs containing `argtuner.toml`) under a root dir.
2. Wire it up as a new `find` CLI subcommand in `src/main.rs`.
3. Add a new "Project Info" TUI window showing the project's paths and live trial count.

## 1. New module `src/discover.rs`
- `pub fn find_projects(root: &Path) -> Vec<PathBuf>` — recursive `std::fs::read_dir` walk.
- A directory is a project iff `dir.join(CONFIG_FILENAME)` (from `crate::constants::CONFIG_FILENAME`) is a file.
- Skip dirs whose name starts with `.` (hidden) and a `SKIPPED_DIRS` const: `target`, `node_modules`, `artifacts`, `.git`, `venv`, `.venv`, `__pycache__`, `dist`, `build`.
- Once a dir is found to be a project, do **not** descend into it (no nested duplicates).
- Sort the result list by path for deterministic output.
- Ignore `read_dir`/permission errors per-directory (best-effort walk).
- Unit tests (in-module, using `tempfile` which is already a dependency): build a temp tree with nested projects, a project under `target/` (must be skipped), a project under a hidden dir (must be skipped), and a non-project dir; assert exact result set and ordering.

## 2. Export from `src/lib.rs`
- Add `pub mod discover;` and `pub use discover::find_projects;`.

## 3. CLI subcommand in `src/main.rs`
- Add to `Commands` enum (clap derive):
  ```rust
  /// Recursively locate argtuner projects
  Find {
      /// Directory to search (defaults to the current directory)
      #[arg(value_name = "DIR")]
      dir: Option<PathBuf>,
  },
  ```
- New match arm in `main()`:
  ```rust
  Commands::Find { dir } => {
      let root = dir.clone().unwrap_or_else(|| std::env::current_dir().expect("current dir"));
      let projects = argtuner::find_projects(&root);
      if projects.is_empty() {
          eprintln!("No argtuner projects found under {}", root.display());
      }
      for p in projects {
          println!("{}", p.display());
      }
  }
  ```
- Add a unit test in the existing `cli_tests` module: `argtuner find` parses (dir optional), and `argtuner find /tmp/x` parses with `dir == /tmp/x`.
