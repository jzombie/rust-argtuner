# Plan: Project discovery utility + CLI `find` + TUI Project Info window

## Goal
1. Add a library utility that recursively locates argtuner projects (dirs containing `argtuner.toml`) under a root dir.
2. Wire it up as a new `find` CLI subcommand in `src/main.rs`.
3. Add a new "Project Info" TUI window showing the project's paths and live trial count.

## 1. New module `src/discover.rs` (uses `walkdir`)
- Add `walkdir = "2.5.0"` to `[workspace.dependencies]` in `Cargo.toml` (already a transitive dep — verified in `Cargo.lock:3386`, so no new build weight) and `walkdir.workspace = true` to `[dependencies]`.
- `pub fn find_projects(root: &Path) -> Vec<PathBuf>` — walk via `WalkDir::new(root).into_iter()` (symlinks are **not** followed by default, so symlink cycles cannot recurse infinitely).
- Manual loop over the iterator using `walker.skip_current_dir()` for skips:
  ```rust
  let mut walker = WalkDir::new(root).into_iter();
  loop {
      let entry = match walker.next() {
          Some(Ok(e)) => e,
          Some(Err(_)) => continue,   // best-effort: skip unreadable dirs
          None => break,
      };
      if !entry.file_type().is_dir() {
          continue;
      }
      // IMPORTANT: only prune *child* dirs. The root entry (depth == 0, name
      // "." or an absolute path) must never be filtered, else `find .` returns
      // nothing.
      let name = entry.file_name().to_string_lossy();
      if entry.depth() > 0 && (name.starts_with('.') || SKIPPED_DIRS.contains(&name.as_ref())) {
          walker.skip_current_dir();          // skip hidden + noise dirs
          continue;
      }
      if entry.path().join(CONFIG_FILENAME).is_file() {
          results.push(entry.path().to_path_buf());
          walker.skip_current_dir();          // don't descend into a found project
      }
  }
  results.sort();
  ```
- `SKIPPED_DIRS`: `target`, `node_modules`, `artifacts`, `venv`, `.venv`, `__pycache__`, `dist`, `build`. (`CONFIG_FILENAME` from `crate::constants`.)
- Unit tests (in-module, using `tempfile`): nested projects found; project under `target/` skipped; project under a hidden dir skipped; result set + ordering exact.
- Symlink-loop termination test gated `#[cfg(unix)]` (creating symlinks requires elevated privileges / Developer Mode on Windows, which would fail standard Windows CI runners):

## 3. CLI subcommand in `src/main.rs`
- Add to `Commands` enum (clap derive):
  ```rust
  /// Recursively locate argtuner projects
  Find {
      /// Directory to search (defaults to the current directory)
      #[arg(value_name = "DIR")]
      dir: Option<PathBuf>,
  },
  ```
- New match arm — **no `.expect()` and no `.clone()`**; handle `current_dir()` failure gracefully via a `Cow<Path>` (binds owned path only when needed):
  ```rust
  Commands::Find { dir } => {
      // `dir` here is `&Option<PathBuf>` (outer `match &cli.command` borrows),
      // so borrow with `match &dir` and keep the owned `PathBuf` alive in the
      // outer scope — no E0597/E0716.
      let root: Cow<Path> = match &dir {
          Some(d) => Cow::Borrowed(d.as_path()),
          None => match std::env::current_dir() {
              Ok(d) => Cow::Owned(d),
              Err(e) => {
                  eprintln!("Error: failed to determine current directory: {e}");
                  std::process::exit(1);
              }
          },
      };
      let projects = argtuner::find_projects(&root);
      if projects.is_empty() {
          eprintln!("No argtuner projects found under {}", root.display());
      }
      for p in projects {
          println!("{}", p.display());
      }
  }
  ```
  - Add `use std::borrow::Cow;` and `use std::path::Path;` to `src/main.rs` imports (currently only `PathBuf` is imported).
- Add a unit test in the existing `cli_tests` module: `argtuner find` parses (dir optional); `argtuner find /tmp/x` parses with `dir == /tmp/x`.
