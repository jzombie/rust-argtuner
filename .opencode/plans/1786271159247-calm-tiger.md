# Plan: Make the starter template a shared, importable artifact in `argtuner-common`

## Goal
Keep the starter `argtuner.toml` template in `crates/common` as a single source of truth that any (current or future) binding can import — not duplicated per binding. Expose it as a string constant (for Rust consumers) and keep the command-substitution helper alongside the canonical asset file (for non-Rust bindings to embed at build time).

## Why
`render_template_toml` + the embedded `assets/template.toml` are currently the only non-constant behavior in `crates/common`, and moving them into `bindings/rust` (as previously planned) would make every future language binding duplicate the starter template. Since `argtuner-common` is a Rust crate, non-Rust bindings can't `use` it directly — but they can embed the same canonical file at build time. So the shared artifact is: one canonical `assets/template.toml` + a `pub const` string + the substitution helper, all in `argtuner-common`.

## Changes

### 1. `crates/common/src/lib.rs`
- Add the template as an importable string constant (replacing the `include_bytes!`-in-function):
```rust
/// Starter `argtuner.toml` skeleton, shared by all bindings. Import as a
/// string, or embed the canonical file at `crates/common/assets/template.toml`
/// at build time from non-Rust bindings.
pub const STARTER_TEMPLATE_TOML: &str = include_str!("../assets/template.toml");

/// Render a starter `argtuner.toml` with the provided template command
/// substituted into the `template` line.
pub fn render_starter_toml(command: &str) -> String {
    STARTER_TEMPLATE_TOML.replace("__ARGTUNER_TEMPLATE__", &escape_toml_string(command))
}

fn escape_toml_string(value: &str) -> String {
    value.replace('\\', "\\\\").replace('"', "\\\"")
}
```
- The fn is renamed `render_template_toml` → `render_starter_toml` for clarity (it renders a starter config; the tuner already has a distinct `CommandTemplate` concept). This is a breaking rename of an internal-shared helper with exactly one caller.
- `assets/template.toml` stays put (`crates/common/assets/template.toml`).

### 2. `bindings/rust/src/lib.rs`
- Update the single caller (src/lib.rs:162) to the renamed fn:
```rust
#[cfg(feature = "clap")]
pub fn render_template_toml<T: clap::CommandFactory>() -> String {
    let template = render_template_command::<T>();
    argtuner_common::render_starter_toml(&template)
}
```
- The public `argtuner_talkback::render_template_toml::<T>()` API is unchanged (still `pub`, same signature), so `tests/talkback_template.rs:16` and `bindings/rust/README.md` need no edits.

### 3. No file moves
- `crates/common/assets/template.toml` remains the canonical file; nothing is copied to `bindings/`.
