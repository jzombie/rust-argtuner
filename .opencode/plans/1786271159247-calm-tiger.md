# Plan: Framework feature — "is the focused window app-owned?" in term-wm + argtuner uses it

## Goal
Promote the core-vs-app window discrimination from an argtuner-local `matches!` into a first-class term-wm API, then simplify argtuner to call it. Answers the user's question directly: **yes, it's a good framework feature — no `WindowManager`-core change needed, the API lives in the facade crate.**

## Why the facade crate (dependency analysis)
`AppRootComponent<C>` = `Core(CoreWmComponent) | Custom(C)` is public (term-wm/src/components.rs:9). A `WindowManager`-level helper referencing `AppRootComponent` cannot live in `term-wm-core` (core does NOT depend on the facade; facade depends on core). So the feature goes in the `term-wm` facade:
- Predicates on `AppRootComponent` (src/components.rs).
- `TermWmApp::focused_is_custom()` / `focused_is_core()` (src/term_wm_app.rs): a `&self` query over the crate-private `wm` field — both `WindowManager::focused_window()` (focus.rs:17) and `component_for_key()` (mod.rs:2319) are `&self`, so no `&mut` needed.

argtuner uses path dep `term-wm = { path = "../term-wm" }` — picked up automatically, no version bump.

## term-wm changes

### 1. `term-wm/src/components.rs` — predicates on `AppRootComponent`
```rust
impl<C> AppRootComponent<C> {
    /// Returns true for app-owned (`Custom`) windows, false for core/system windows.
    pub fn is_custom(&self) -> bool {
        matches!(self, AppRootComponent::Custom(_))
    }
    /// Returns true for core/system windows, false for app-owned (`Custom`) windows.
    pub fn is_core(&self) -> bool {
        matches!(self, AppRootComponent::Core(_))
    }
}
```
- `///` doc comments are required (term-wm CI runs `RUSTDOCFLAGS="-D warnings" cargo doc`).
- Add `#[cfg(test)] mod tests`: for `AppRootComponent::Custom(NoopComponent)` assert `is_custom()==true`/`is_core()==false`; for `AppRootComponent::Core(CoreWmComponent::Noop(NoopComponent))` assert the reverse. (`NoopComponent` re-exported at components.rs:1; `CoreWmComponent` already imported at components.rs:6.)

### 2. `term-wm/src/term_wm_app.rs` — focus query on `TermWmApp`
Add to the existing `impl<C: Component<TermWmAction>> TermWmApp<C>` block (line 135):
```rust
/// Returns true when the currently focused window is an app-owned
/// (`AppRootComponent::Custom`) window, as opposed to a core/system window.
pub fn focused_is_custom(&self) -> bool {
    self.wm
        .component_for_key(self.wm.focused_window())
        .is_some_and(AppRootComponent::is_custom)
}
/// Returns true when the currently focused window is a core/system window.
pub fn focused_is_core(&self) -> bool {
    self.wm
        .component_for_key(self.wm.focused_window())
        .is_some_and(AppRootComponent::is_core)
}
```
Add tests to the existing `#[cfg(test)] mod tests` (term_wm_app.rs:576), following the `new_custom_*` pattern (`TermWmApp::<NoopComponent>::new_custom(AppContext::new("test", "0.0.0"))`):
- Open `AppRootComponent::Custom(NoopComponent)` and `AppRootComponent::Core(CoreWmComponent::Noop(NoopComponent))` via `app.open_window(...)`; map both if `open_window` leaves them unmapped (`app.wm().transition_window(k, WindowState::Mapped)`, mirroring runner.rs:1520-1547); `app.wm().focus_window_key(k)` each; assert `focused_is_custom()`/`focused_is_core()` flip correctly.

## argtuner changes — `src/tui/mod.rs`
- **Delete** the `focused_window_is_app()` method (logic moves into the framework).
- `handle_app_event` now uses the framework query:
```rust
fn handle_app_event(&mut self, event: &Event) -> bool {
    // filter keeps this a single if-let: no let-chains (pre-1.88 stable)
    // and no `clippy::collapsible_if`.
    if let Some(key) = pressed_key(event).filter(|_| self.inner.focused_is_custom()) {
        let kb = self.inner.wm().keybindings();
        if kb.matches(TermWmAction::Quit, key) {
            self.open_exit_confirm();
            return true;
        }
        if kb.matches(TermWmAction::Custom(1), key) {
            self.chart_mode = match self.chart_mode {
                ChartMode::Metrics => ChartMode::HyperParams,
                ChartMode::HyperParams => ChartMode::Metrics,
            };
            self.apply_chart_mode();
            return true;
        }
    }
    self.inner.handle_app_event(event)
}
```
- `self.inner.focused_is_custom()` is `&self` on `TermWmApp` — shared borrow, ends before the body's `&mut self` calls.
- `pressed_key` + `key_tests` unchanged.
