# Plan: Upgrade `toml` to 1.1.4 + library-backed escaping in `render_starter_toml`

## Goals
1. Bump the TOML dependency to the modern latest (`toml` 1.1.4, released 2026-07-28) — the repo pins 0.9.10 (2025-12).
2. Fix the hand-rolled `escape_toml_string` using the (now-current) `toml` serializer, keeping `assets/template.toml` and the `STARTER_TEMPLATE_TOML` const as-is (per the user's direction — the file stays).

## Research findings (verified)
- Current stable: `toml` = **1.1.4**, `toml_edit` = 0.25.13 (not a dependency here).
- `toml` 1.0.0 (2026-02-11) breaking changes are tiny: `Time::second`/`Time::nanosecond` → `Option`, and borrowed-`&str` deserialization support. None affect this repo's call sites.
- `toml` 1.1.4 (docs.rs) still exports `toml::from_str`, `toml::to_string`, `toml::to_string_pretty`, and `toml::Value` (enum with `String(String)` variant) whose `Display` serializes through the TOML serializer → a fully quoted + escaped literal. MSRV 1.85 (fine — repo is edition 2024).
- Blast radius of `toml::` usage (grep): `src/project/mod.rs` (`from_str` ×3, `to_string_pretty`), `tests/config_validation.rs` (`from_str`), `tests/talkback_template.rs` (`from_str`), plus the new `crates/common` use. No custom `Time`/`Datetime` fields involved.
- Transitive deps bump along with `toml` 1.1: `toml_parser` 1.1.3, `toml_writer` 1.1.2, `toml_datetime` 1.1.1, `serde_spanned` 1.1.1, `winnow` 1.0, `serde_core` — all resolved via `Cargo.lock` regen (all already in the tree at 1.0.x).

## Changes

### 1. `Cargo.toml` (workspace dependencies)
`toml = "0.9.10"` → `toml = "1.1"` (resolves to 1.1.4).

### 2. `crates/common/Cargo.toml`
Add to the empty `[dependencies]`:
```toml
[dependencies]
toml.workspace = true
```

### 3. `crates/common/src/lib.rs`
Replace the hand-rolled escape and delete `escape_toml_string`:
```rust
/// Render a starter `argtuner.toml` with the provided template command
/// substituted into the `template` line. The command is embedded as a TOML
/// basic string via the `toml` serializer (escaping fully library-handled).
pub fn render_starter_toml(command: &str) -> String {
    STARTER_TEMPLATE_TOML.replace(
        "__ARGTUNER_TEMPLATE__",
        &toml::Value::String(command.to_string()).to_string(),
    )
}
```
- `STARTER_TEMPLATE_TOML` const unchanged (`include_str!("../assets/template.toml")`).

### 4. `crates/common/assets/template.toml`
Line 1 — remove the quotes around the placeholder (the library-provided literal includes its own quotes):
```toml
template = __ARGTUNER_TEMPLATE__
```

### 5. `Cargo.lock`
Regenerated (`cargo build`/`cargo update -p toml`) to record `toml` 1.1.4 + transitive bumps.
