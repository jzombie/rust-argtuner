# Total `talkback` eradication: `#[tuner_args]` + IPC protocol naming

The term "talkback" was meant for the JSON protocol, but `#[talkback_args]` came to mean CLI
params. Rename the whole concept with **zero `talkback` left behind** (no deprecation
aliases). New naming:
- `#[talkback_args]` → **`#[tuner_args]`** (derive macro)
- `Talkback` (SDK handle) → **`IpcChannel`**
- `TalkbackMessage` (wire enum) → **`IpcMessage`**
- `PROTOCOL_NAME` value `"argtuner.talkback"` → **`"argtuner.ipc"`**; schema title →
  "argtuner ipc protocol"
- parser module `subprocess/talkback.rs` → **`subprocess/ipc.rs`**
- `tests/talkback_template.rs` → **`tests/tuner_args.rs`**

Runtime safety: `PROTOCOL_NAME` is used only in the generated schema's
`x-argtuner.protocol` metadata — the parser frames on the `::ARGTUNER::` prefix
(`src/command/subprocess/talkback.rs:32-40`), never on the protocol string. So the wire
change is descriptive, not a framing change. Deprecated shims `argtuner-talkback*` are
already deleted by the user.
