# Purge `Args` from test/example struct names → `*Params`

Completes the `Args` purge under the **Tuner Param** standard: rename every
`*Args` tuner-param struct and its `(channel, args)` locals to `*Params`/`params`.
No README/doc references these struct names — the change is confined to the
example and test sources.

## 1. `tests/tuner_params.rs`
- `TemplateArgs` → `TemplateParams` (struct + all `render_template_toml::<…>` /
  `render_template_command::<…>` refs)
- `TrickyArgs` → `TrickyParams`
- `BoolParamArgs` → `BoolParams` (avoids double-"Param")
- `OptionalArgs` → `OptionalParams`

## 2. Examples
- `examples/linear_regression/main.rs`: `ExampleArgs` → `ExampleParams`;
  `let (_channel, args)` → `let (_channel, params)`
- `examples/pareto_demo/main.rs`: `ParetoArgs` → `ParetoParams`;
  `let (_channel, args)` → `(_channel, params)`
- `examples/interactive_probe/main.rs`: `ProbeArgs` → `ProbeParams`
  (already uses `(channel, parsed)` — no `args` local)
- `examples/loss_pattern_generator/main.rs`: `Args` → `Params`;
  `let (channel, args)` → `(channel, params)`

## Verification
1. `git grep -nE "struct [A-Za-z0-9_]*Args"` → zero.
2. `cargo build --workspace`
3. `cargo test --workspace --all-features`
4. `cargo clippy --workspace --all-targets --all-features -- -D warnings`
5. `cargo run -p argtuner --example linear_regression -- --print-template` still renders.
