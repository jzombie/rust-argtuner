# Self-describing talkback protocol: shared types + `protocol.schema.json`

## Goal

Make the `::ARGTUNER::` stdio protocol self-describing **without changing the wire format**:

1. `schemars` derives on the protocol types → canonical `protocol.schema.json` committed in-repo + a `--print-protocol-schema` flag on talkback binaries.
2. Centralize the wire types in `crates/common` so the emitter (`bindings/rust/src/lib.rs`) and parser (`src/command/subprocess/talkback.rs`) share ONE model (no hand-built `json!` maps, no duplicated parser enum).
3. Drift test: regenerate schema from types, compare to the committed file.
4. Schema documents the **framing** layer (prefix, ANSI-strip, line-scoped scan) as an `x-argtuner` extension, and validates the JSON payload structurally. (JSON Schema cannot validate the prefix/ANSI — they live outside the JSON document.)

## Verified research (do not re-do)

- **schemars** is at **1.2.2** (2026-07-27). MSRV 1.74, deps `serde ^1.0.194` / `serde_json ^1.0.127` — compatible with workspace serde 1.0.228, edition 2024, rustc 1.97.
  - Derive **fully supports** `#[serde(tag = "type")]` internally-tagged enums (`tag`/`content`/`untagged` are listed under supported serde attrs). Struct variants + `rename_all = "lowercase"` produce a clean root object with `oneOf`: each branch is the variant's object schema with the `type` tag as `"enum": ["event"]` / `"enum": ["result"]` and tag in `required`. This is the recommended approach — no hand-written `JsonSchema` impl and no `#[schemars(untagged)]` needed.
  - `Schema` (1.x) is a thin wrapper over `serde_json::Value`; `json_schema!({...})` builds one with json!-style interpolation. `schema_for!(T)` uses current default settings (draft 2020-12); explicit pin via `SchemaSettings::draft2020_12().into_generator().into_root_schema_for::<T>()`.
  - `#[schemars(schema_with = "fn")]` supported on fields (`fn(&mut SchemaGenerator) -> Schema`).
  - `BTreeMap<String,String>` → `{"type":"object","additionalProperties":{"type":"string"}}`. `#[serde(default)]` keeps `fields` out of `required`.
  - **No preserve_order** in repo → `serde_json::Map` is BTreeMap-backed → **byte-stable sorted key order** → deterministic schema output, safe for the drift test.
- **jsonschema** crate is now **~0.42** (repo README shows `version = "0.42"`; schemars itself dev-depends on `^0.30`). API: `jsonschema::validator_for(&schema)?.validate(&instance)` / `.is_valid(&instance)`; draft auto-detected; full draft 2020-12 support incl. `$defs`, `oneOf`, `enum`, `additionalProperties`. Use `default-features = false` to avoid the default `aws-lc-rs` TLS stack (no network needed).
- **Current wire key order**: `serde_json::json!` objects sort keys (BTreeMap) → today the emitter writes `{"fields":…,"name":…,"type":…}`. Serializing the shared derived enum writes declaration order `{"type":"event","name":…,"fields":…}`. **JSON object order is semantically irrelevant**; the parser is serde-based and order-independent; no test asserts byte-exact output (verified: runner.rs:433-456 and all `emit_*` bins feed the serde parser). The new order actually matches the README's documented examples (README.md:58-59).
- `.codegraph/` exists; `emit_event` (9 callers incl. 4 `src/bin/emit_*` bins + `Talkback::init`), `parse_output`/`parse_prefix_lines` (1 caller each: `src/command/subprocess/runner.rs:32`, `mod.rs:6`).

## Design

### 1. Shared protocol module — `crates/common/src/protocol.rs` (NEW)

```rust
use std::collections::BTreeMap;
use schemars::{JsonSchema, Schema, SchemaGenerator, json_schema};
use serde::{Deserialize, Serialize};

/// Exactly the current wire shape. `name` stays a plain `String` so
/// un-namespaced aliases still parse (EventKind::from_name applied downstream).
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
#[serde(tag = "type", rename_all = "lowercase")]
pub enum TalkbackMessage {
    Event {
        #[schemars(schema_with = "event_name_schema")]
        name: String,
        #[serde(default)]
        fields: BTreeMap<String, String>,
    },
    Result {
        #[serde(default)]
        fields: BTreeMap<String, String>,
    },
}

/// canonical + un-namespaced alias, one entry each, in EventKind order.
pub const EVENT_NAME_VALUES: &[&str] = &[
    MODEL_EPOCH_END_EVENT, EPOCH_END_EVENT,
    MODEL_STEP_END_EVENT, STEP_END_EVENT,
    MODEL_EARLY_STOPPED_EVENT, EARLY_STOPPED_EVENT,
    MODEL_INVALID_CONFIG_EVENT, INVALID_CONFIG_EVENT,
    TUNER_BINDING_VERSION_EVENT, BINDING_VERSION_EVENT,
];

fn event_name_schema(_: &mut SchemaGenerator) -> Schema {
    json_schema!({ "type": "string", "enum": EVENT_NAME_VALUES })
}
```

Plus (module contents):
- `pub fn strip_ansi(line: &str) -> String` — moved verbatim from `src/command/subprocess/talkback.rs:91-124` (only framing implementation, shared).
- `pub fn extract_talkback_json(line: &str, prefix: &str) -> Option<String>` — ANSI-strip → find `prefix` → `trim()` the rest → `None` if empty. Single shared framing implementation (parser's `parse_output`/`parse_prefix_lines` delegate to it).
- `pub fn framing_metadata() -> serde_json::Value` — the `x-argtuner` extension object (see §3).
- `pub fn protocol_schema() -> serde_json::Value` — root schema + `x-argtuner`.
- `pub fn protocol_schema_json() -> String` — `to_string_pretty` + `"\n"` (byte-stable).
- `#[cfg(test)]` tests (see Test list).

`crates/common/src/lib.rs`: add `pub mod protocol;` and `pub use protocol::TalkbackMessage;`. Keep `RESULT_PREFIX`, `EventKind`, constants where they are (protocol.rs references `crate::RESULT_PREFIX`, `crate::EventKind`).

**Sync guarantee for the `name` enum**: a test asserts `EVENT_NAME_VALUES` == exactly {for each `EventKind` variant except `Result`: `as_str(k)` + the matching un-namespaced alias}. If someone adds an event name to `EventKind` without updating `EVENT_NAME_VALUES`, the test (not just the drift test) fails loudly.

### 2. Parser refactor — `src/command/subprocess/talkback.rs`

- `use argtuner_common::protocol::{TalkbackMessage, extract_talkback_json};`

### 3. Schema generation + framing metadata

```rust
pub fn protocol_schema() -> serde_json::Value {
    let root = SchemaSettings::draft2020_12().into_generator()
        .into_root_schema_for::<TalkbackMessage>();
    let mut value = serde_json::to_value(root).expect("root schema serializes");
    value.as_object_mut().expect("object")
        .insert("x-argtuner".to_owned(), framing_metadata());
    value
}
```

`framing_metadata()` shape (documents the framing layer; JSON Schema cannot validate the prefix/ANSI because they are outside the JSON document — this is the honest answer the user expects):

```json
"x-argtuner": {
  "framing": {
    "prefix": "::ARGTUNER::",
    "stripAnsiEscapes": true,
    "lineScoped": true,
    "match": "Each stdout line is stripped of ANSI escapes, then scanned for the first occurrence of `prefix`; the JSON document is the remainder of that line, trimmed. Lines without the prefix are ignored."
  },
  "note": "This schema validates the JSON document payload only. The ::ARGTUNER:: prefix and ANSI escapes live outside the JSON document (framing) and are not representable in JSON Schema.",
  "eventNames": "Canonical names and un-namespaced aliases are both valid `name` values; the parser forwards unknown names to EventKind::from_name which rejects them."
}
```

Post-processing the serialized `Value` avoids depending on schemars' internal object model (`ObjectValidation`/`RootSchema` field shapes changed in 1.x). Deterministic: all maps are BTreeMap-backed.

### 7. Real-line validation (optional but recommended)

- `jsonschema` as a dev-dependency of `argtuner-common` (`default-features = false`).
- `crates/common/tests/protocol_schema.rs`: load committed schema, `jsonschema::validator_for(&schema)`, then for each representative framed line: `extract_talkback_json(line, RESULT_PREFIX)` → `serde_json::from_str` → `validator.validate(...)`. Cases:
  - `::ARGTUNER::{"type":"event","name":"model.epoch_end","fields":{"metric":"0.123","aux":"42","epoch":"1"}}` (README.md:58)
  - `::ARGTUNER::{"type":"event","name":"model.early_stopped","fields":{}}` (README.md:59)
  - `::ARGTUNER::{"type":"result","fields":{"metric":"0.42"}}` (result shape from pso.rs:506)
  - alias: `::ARGTUNER::{"type":"event","name":"epoch_end","fields":{}}`
  - ANSI-wrapped: `\x1b[1m::ARGTUNER::{"type":"event","name":"model.step_end","fields":{}}\x1b[0m`
  - negative: bad event name (`"name":"model.nope"`) and non-string field value must FAIL.

## Backward-compat & risk list

1. **Wire byte identity**: object **key order** changes (`fields,name,type` → `type,name,fields`). Semantically identical (JSON objects unordered; serde parser order-independent); no test asserts bytes; new order matches README docs. **No functional break.**
2. **schemars oneOf**: internally-tagged derive output is tidy and deterministic; the drift test + committed file lock the exact shape. `schema_with` on the Event variant's `name` field is a supported derive attribute.
3. **Unknown event names**: the schema `enum` lists only known canonical+alias names, so a future name fails schema validation even though the parser tolerates it. Documented in the `x-argtuner` note; schema is intentionally the canonical contract.
4. **Macro injection**: no existing struct defines `print_protocol_schema` (verified: 5 `#[talkback_args]` sites). Injection is additive; clap bool flag takes no value; `init_with_args` intercepts before `T::parse()`.
5. **Template skip list**: must include `print-protocol-schema` or the rendered template leaks the flag (would also break `tests/talkback_template.rs`'s template-shape assertions if it ever grew).
6. **`argtuner-common` deps**: adds serde/serde_json/schemars (schemars pulls `schemars_derive`=syn 3, `dyn-clone`, `ref-cast`). No conflict — the repo's proc-macro crate uses syn 2 separately, and serde 1.0.228 ≥ schemars' ^1.0.194.
7. **jsonschema**: `default-features = false` avoids `aws-lc-rs`; draft 2020-12 supported; MSRV 1.83 < 1.97.
8. **Framing not in JSON Schema**: prefix/ANSI documented only as metadata (`x-argtuner`) — validated structurally by the jsonschema test that strips framing first.
